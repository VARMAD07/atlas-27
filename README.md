# ATLAS 27 — Hammad's Engineering Decision Desk

A self-contained admissions research and decision workspace covering India and international undergraduate routes for Mohammad Hammad Faridi.

## What's inside

- 13 Indian college dossiers
- 28 international route dossiers
- scholarship and opening watchlists
- dates, costs, funding and document tracking
- comparison and shortlist tools
- offline evidence lookup
- application checklist and notes
- print/PDF and export tools
- optional AI-chat workflow

## Research snapshot

The dossier itself records its research snapshot and source-check dates. Re-check official university, government and scholarship notices before relying on any deadline, eligibility rule, fee, funding condition or admission policy.

## Run locally

Open `index.html` in a modern browser. The main dossier works as a standalone HTML file.

The AI-chat section is designed for an online deployment with its corresponding `/api/chat` endpoint; the static GitHub Pages copy may therefore leave that feature unavailable while the offline research sections remain usable.

## GitHub Pages

This repository is intended to be published as a static GitHub Pages site from the `main` branch.
